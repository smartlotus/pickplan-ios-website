本机无 Xcode？用 GitHub Actions 云端免费构建 + Sideloadly 安装

如果本地 Mac 未安装完整 Xcode，只需把仓库内 docs/ci/build-unsigned-ipa.yml 放到 .github/workflows/，GitHub 免费 macOS Runner 会自动编译测试并输出 PickPlan-Unsigned.ipa；随后在 Windows 或 Mac 上拖入 Sideloadly / 爱思助手 签名装入设备。

gh auth refresh -h github.com -s workflow mkdir -p .github/workflows cp docs/ci/build-unsigned-ipa.yml .github/workflows/ git add .github/workflows && git commit -m "Enable cloud IPA build" && git push

Pickplan Android → iOS/iPadOS 原生移植对照

在深入分析原仓库 main 与 wip/monorepo-migration 分支后，原生 SwiftUI 版完整还原核心操作流并进化如下：

  • 1:1 视觉与手势还原：保留暖白 900ms 呼吸开屏（pickplanlogo.jpg）、纯黑高对比卡片、🔔 测试推送、↻ 刷新 Toast 与单点删除 Undo，并升级为 SwiftUI 26 GlassEffectContainer。
  • iPhone 与 iPad 双端原生：iPhone 采用三态悬浮液态玻璃胶囊 + + 新任务悬浮 Pill；iPad 采用三栏 NavigationSplitView + 键盘快捷键 + 专注计时检查器。
  • AI 引擎与逐条确认：完整保留 7 大 AI 预设与 GET /models 检测，支持每张草稿单独「编辑」「加入」及无网离线大白话解析。
  • 本地数据主权：从 SharedPreferences 升级为 CryptoKit SHA256 本地金库，支持每日定时备份时刻、快照任务预览、Files 文件夹互通与 Android v1 导入。

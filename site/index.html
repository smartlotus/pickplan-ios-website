Pickplan Android → iOS/iPadOS 移植架构对照

在深入分析原仓库 main 与 wip/monorepo-migration 分支后，iOS 版保留全部核心能力并完成以下全面进化：

  • 视觉与动效：从 Flutter 黑白描边升级为 SwiftUI 26 GlassEffectContainer 与物理弹簧曲线，支持 iOS Reduce Motion 与触感反馈。
  • 双端适配：iPhone 采用底部形变胶囊导航，iPad 采用三栏 NavigationSplitView + 键盘快捷键 + Stage Manager 多尺寸适配。
  • 离线大白话：在保留 DeepSeek / Kimi / Qwen / GLM / SiliconFlow / OpenAI 预设的同时，内置离线中英时间语义拆解器。
  • 数据主权：SharedPreferences 升级为 PickPlanBackupEnvelope v2（SHA256 校验）、定时自动快照、Files 共享与三策略安全导入。

.pickplan.json v2 跨端备份规范
